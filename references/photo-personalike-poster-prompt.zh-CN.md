# Photo Personalike Poster 完整生图规范

## 通用执行

先判断上传照片属于 **人物** 还是 **风景**。默认生成一张竖版 4:5 成图；用户指定比例时遵从用户。内部执行 `OBSERVE → PRESERVE → DISTILL → STYLIZE → COMPOSE → CHECK`，不向用户展示中间分析。

从照片提取高信息内容，删除摄影噪声、低信息杂物和可识别品牌。成图必须首先被读作二维动画或赛璐璐插画，不得是照片滤镜、半写实游戏原画或三维渲染。

## 风格借鉴边界

人物采用原创、反叛的波普风格二维海报：以青春动势、拼贴撕裂感和高对比图形关系为目标。风景借鉴游戏过场动画中常见的高饱和、多色、电影化光线、分层空间和单一情绪焦点。两者都只借鉴抽象方法，不得复刻任何游戏截图、角色、界面、文字、镜头框选、构图、配饰、Logo 或某个具体作品的可识别视觉签名。

## 人物模式：原创波普朋克二维海报

### 身份锁定

保留人物可辨识身份与年龄感：基本脸型、发际线和发型、眼睛方向、表情、头部倾角、身体姿势、手臂交叉关系、服装类型、眼镜/护目镜/面罩和具有身份意义的物件。允许动画化简化，但不得美化、年轻化、性别转换、改变族裔特征、增加肌肉或改写体型。

### 视觉语法

- 画面必须是清晰的二维动画：完整且粗细变化明显的黑色外轮廓、块状动画头发、简化但保留身份的五官、硬边赛璐璐阴影、每个表面两至三级明暗色块。
- 用猩红色作为主导，高饱和群青只作小面积深度点缀；其余为黑、炭灰、中性灰和冷白。让红色承担冲击，群青承担空间深度，不能反客为主。
- 人物占主要视觉区域。使用倾斜、断裂、不对称的面板分区，大黑色底座与红色高冲击楔形制造人物登场方向。
- 强化撕裂海报的反叛青春感：让身体朝向、衣料褶皱、红色楔形、重复轮廓和错位套印指向同一运动方向；使用撕纸边、粗黑分隔、网点、局部白色负空间和少量剪纸块面。画面应像人物正冲入舞台，避免静态证件照式正中构图。
- 可在不遮挡脸、眼睛、手势或关键装备的前提下，选择性加入零至三个原创辅助元素：抽象面具、虚构武器、伴生动物、花束、背景角色剪影、信号图形或原创 UI。它们只服务人物气质，不得替代人物、使用既有角色设计，或暗示某个具体作品。
- 可以加入短的原创英文文字或图形化 UI；文字使用 Arial，通常一至三个词，清晰但不应压过人物。若用户提供标题，逐字只出现一次。禁止游戏名、商标、品牌、真实 Logo、可识别菜单、签名、水印及模仿现有 UI 的专有文案。

### 避免

避免毛孔、真实皮肤纹理、自然肤色、单根写实发丝、摄影景深、镜头光晕、柔软写实渐变、油画笔触、塑料人偶感、三维渲染和直接照片滤镜。若首次结果仍明显写实，只做一次针对线稿、五官简化、硬边阴影和材质平面化的定向修正。

## 风景模式：多彩二维动画场景

### 场景锁定

保留地标、镜头高度、主要透视关系、时间/天气和三至六个最有信息量的场景事实。例如桥梁跨度与索线、河面与天际线、鸟居通道的节奏、寺院屋檐和人流、街巷层级或夜间灯光。

### 视觉语法

- 使用与场景相称的协调多色调色板；天空、水面、植被、灯光和建筑可以有不同颜色。不要把人物模式的红黑灰白限色强加给风景。
- 用原创的动画电影感组织画面：明确前景、中景、远景；用屋檐、桥梁、道路、树冠、栏杆、河岸或人群轮廓引导视线；以日光、灯笼、霓虹、反射、云隙或其他来源可推导的光建立一个焦点。
- 将真实材质压缩为清晰轮廓、简洁线稿、两至三级赛璐璐明暗与柔和但克制的空气透视。将冷暖色分层：前景可较深，中景承载主要色彩，远景和天空保留高明度光；允许少量颗粒、横向光带、云缘辉光或网点，不能盖过地点本身。
- 可以加入一项由原场景推导的环境动作，例如水面波纹、车流光带、风吹旗帜、远处烟火般的抽象光团或灯笼亮起。不得凭空增加主要人物、动物、车辆、怪物或新叙事道具。
- 默认不生成可读文字。删除或抽象化源照片中的招牌、品牌、Logo、广告、版权角色和水印；不得以伪文字替代。

### 特殊来源处理

若照片含主题公园、受保护建筑、商业招牌、屏幕角色或显著商标，只保留非识别性的空间关系、自然光、普通建筑轮廓和镜头情绪；删除能识别出特定品牌、作品或地点设计的细节。不得把任何参考 CG、截图或网络图作为输出素材或直接复刻其构图。

## 交付前检查

- 模式是否正确：人物首先像人物海报；风景首先像有空间层次的动画场景。
- 人物是否仍可辨识，姿势、手部、眼镜和面罩是否结构合理。
- 风景是否保留地点事实、层次与焦点，同时清除了品牌和可识别 IP。
- 人物是否由猩红主导并仅以小面积群青增深；风景是否采用自然、丰富且协调的多色调。
- 是否出现写实质感、Logo、商标、水印、伪文字、受版权保护的角色特征或未授权新增人物。

## 示例边界

示例文件成对保存为 `<subject>-source.*` 与 `<subject>-portrait-punk.png` 或 `<subject>-landscape-cinematic.png`。它们仅展示二维化程度、色彩逻辑、层级、阴影和构图强度；不得复制人物、地点、服装、姿势、道具、文字或具体构图。
